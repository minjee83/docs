# 🛒 상품 목록 페이지 프로젝트

---

## 1. 프로젝트 개요

### 프로젝트 목적
본 프로젝트는 사용자가 다양한 상품을 확인하고, 원하는 상품을 장바구니에 추가할 수 있는 상품 목록 페이지를 구현하는 것을 목표로 합니다.

### 주요 기능
- 상품 목록 조회 기능
- 상품 상세 정보 표시 기능
- 장바구니 추가 기능
- 수량 선택 기능
- 상태 관리 기반 UI 업데이트

### 참여 팀원
- 상품 목록 UI 구현

## 4. 컴포넌트 구조
```
src
 ├── components
 │    ├── ProductList.jsx
 │    ├── ProductCard.jsx
 │    ├── CartButton.jsx
 │    └── Header.jsx
 └── App.jsx
```

- 주요 컴포넌트 설명

ProductList: 상품 데이터를 반복 렌더링

ProductCard: 컴포넌트에 props 전달

ProductCard: 개별 상품 정보 표시 (이름, 가격, 이미지)

CartButton: 클릭 시 장바구니 상태 업데이트

App: 전체 상태 관리 및 최상위 컴포넌트

## 5. 테스트 항목

- 상품 목록 정상 렌더링 여부

- 수량 증가/감소 기능 정상 동작 여부

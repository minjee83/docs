# 🛒 상품 목록 페이지 리뷰

---

## 1. 고객사 요구사항

> 이메일 요구사항과 피그마 시안을 기반으로 기능을 구현하였습니다.

1. 모바일 환경에서의 사용성 최적화
2. 신발 사진이 디자인 시안과 동일한 비율로 선명하게 표시
3. 장바구니 추가 시 헤더에 실시간 상품 개수 표시
4. 테스트 가능한 배포 URL 제공

---

## 2. 요구사항에 따른 기능 동작 확인

---

### 1️⃣ 모바일 환경 구성

#### ✔ 반응형 레이아웃 적용
- CSS Media Query를 사용하여 768px 이하에서 모바일 레이아웃 적용
- 상품 카드가 1열 구조로 변경되도록 구성
- 버튼 터치 영역 최소 44px 이상 확보

#### ✔ 실제 테스트 환경
- iPhone Safari 브라우저에서 정상 동작 확인
- 삼성 인터넷 브라우저에서 UI 깨짐 없이 정상 렌더링 확인
- Chrome DevTools 모바일 모드 테스트 완료

#### ✔ 확인 항목
- 스크롤 정상 동작
- 버튼 클릭 시 오작동 없음
- 폰트 및 이미지 비율 유지

---

### 2️⃣ 신발 상품 사진

#### ✔ 디자인 시안 기준 반영
- 피그마 시안의 이미지 비율(1:1)을 유지하도록 `object-fit: cover` 적용
- 이미지 컨테이너에 고정 비율 적용
- 고해상도 이미지 사용으로 화질 저하 방지

#### ✔ UX 개선 요소
- 이미지 로딩 전 Skeleton UI 적용
- hover 시 확대 효과 (PC 환경)

---

### 3️⃣ 장바구니 담기 기능

#### ✔ 기능 동작 방식
- 상품 카드의 "장바구니 추가" 버튼 클릭 시 상태 값 증가
- React useState를 활용한 전역 상태 관리
- 동일 상품 추가 시 수량 증가 처리

#### ✔ 헤더 실시간 반영
- 장바구니 개수 상태를 Header 컴포넌트에 props로 전달
- 장바구니 추가 즉시 헤더 숫자 자동 업데이트
- 새로고침 전까지 상태 유지

#### ✔ 예외 처리
- 수량이 0일 경우 표시 제거
- 최대 수량 초과 시 경고 메시지 출력

---

### 4️⃣ 배포 URL

#### ✔ 배포 환경
- Vercel을 통한 배포

#### ✔ 테스트 URL
https://your-deployment-url.vercel.app

#### ✔ 확인 방법
- 위 URL 접속 후 상품 목록 페이지 진입
- 상품 추가 시 헤더 카운트 증가 여부 확인
- 모바일 환경에서 레이아웃 자동 변경 확인

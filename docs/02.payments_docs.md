# 💳 Shooking Payment Module

카드 등록 및 결제를 위한 React 기반 결제 모듈입니다.
입력값 유효성 검사와 카드 민감 정보 마스킹 처리를 중심으로 구현했습니다.

---

## ✨ Features

* 카드 등록 기능
* 구매 버튼 결제 처리
* 카드 번호 자동 하이픈 포맷팅 (0000-0000-0000-0000)
* 만료일 자동 포맷 (MM/YY)
* 카드 민감 정보 마스킹 처리 (CVC, 비밀번호)
* 입력값 실시간 유효성 검증
* 반응형 UI

---

## 🛠 Tech Stack

* React 18
* JavaScript (ES6+)
* CSS
* npm

---

## 🚀 Getting Started

### 1. Install

```bash
npm install
```

### 2. Run

```bash
npm start
```

* Local: [http://localhost:3000](http://localhost:3000)
* Deploy: [https://shooking-pay.vercel.app](https://shooking-pay.vercel.app)

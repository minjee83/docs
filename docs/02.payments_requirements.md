# 결제 모듈 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 
슈킹 온라인 결제 모듈

### 사용하게 될 기술: 
React

### 문서 작성자: 
구민지

## 📝 고객 요구사항 정리
- 사용자는 카드 정보를 입력하여 상품을 구매할 수 있어야 한다.
- 카드 등록 기능이 제공되어야 한다.
- 카드 번호, 보안코드, 카드 비밀번호 등 민감 정보는 화면에 그대로 노출되지 않아야 한다.
- 카드 입력 시 숫자만 입력 가능해야 한다.
- 구매 버튼 클릭 시 유효성 검증 후 결제가 진행되어야 한다.
- 배포 URL을 통해 실제 서비스 접속이 가능해야 한다.

## 📋 기능 목록

1️⃣ 구매 버튼 기능 요구사항 <PurchaseButton />

사용자가 "구매하기" 버튼 클릭 시 다음 절차가 실행되어야 한다.

모든 입력 필드 유효성 검사 수행

필수값 누락 시 오류 메시지 표시

유효성 통과 시 결제 요청 처리

성공 시 결제 완료 메시지 표시

실패 시 오류 안내 메시지 표시

버튼은 유효성 검증 통과 전까지 비활성화 가능

2️⃣ 카드 등록 기능 요구사항 <RegisterCardButton />

사용자는 카드 정보를 입력 후 등록할 수 있어야 한다.

등록 완료 시 저장 성공 메시지를 표시해야 한다.

카드 정보는 민감 정보를 제외한 형태로 저장/표시해야 한다.

예: 1234---5678

이미 등록된 카드가 있을 경우 목록 형태로 보여줄 수 있어야 한다.

3️⃣ 카드 번호 입력 기능 요구사항 <CardNumberInput />

입력값은 숫자만 허용

최대 16자리 제한

4자리 단위 자동 하이픈 처리 (예: 1234-5678-9012-3456)

실시간 유효성 검증 수행

화면 표시 시 마스킹 가능

잘못된 형식 입력 시 오류 메시지 출력

4️⃣ 만료일 입력 기능 요구사항 <ExpiryDateInput />

입력 형식: MM/YY

숫자만 입력 가능

월은 01~12 범위만 허용

현재 날짜 이전의 만료일은 허용하지 않음

자동 슬래시("/") 처리

형식 오류 시 즉시 경고 메시지 표시

5️⃣ 카드 소유자 입력 기능 요구사항 <CardOwnerInput />

영문 대문자 입력 권장

특수문자 및 숫자 입력 제한

최소 2자 이상 입력 필수

공백 포함 가능

입력 누락 시 오류 메시지 출력

6️⃣ 보안코드(CVC) 입력 기능 요구사항 <SecurityCodeInput />

숫자만 입력 가능

3자리 또는 4자리 제한

입력 시 전체 마스킹 처리 (●●●)

입력값은 화면에 그대로 노출되지 않아야 함

길이 부족 시 오류 메시지 출력

7️⃣ 카드 비밀번호 입력 기능 요구사항 <CardPasswordInput />

숫자만 입력 가능

2자리 입력

입력 즉시 마스킹 처리

저장 시 평문 저장 금지

입력 누락 또는 길이 오류 시 경고 표시

8️⃣ 카드 민감 정보 보안 요구사항

카드 번호 전체 노출 금지

보안코드, 카드 비밀번호는 입력 즉시 마스킹 처리

콘솔 로그 출력 금지

상태값 디버깅 시 민감 정보 제거 처리

네트워크 요청 시 HTTPS 사용 필수

9️⃣ 배포 URL 요구사항

실제 접근 가능한 URL 제공

HTTPS 프로토콜 사용

최신 브라우저에서 정상 동작

모바일 반응형 지원

예시:

https://shooking-pay.vercel.app

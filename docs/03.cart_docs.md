
# 장바구니 프로젝트

## 프로젝트 개요

본 프로젝트는 쇼핑몰에서 사용되는 장바구니 페이지를 구현하는 것을 목표로 합니다.  
사용자는 장바구니에 담긴 상품을 확인하고 총 금액을 계산할 수 있으며, 배송비 정책에 따라 최종 결제 금액을 확인할 수 있습니다. 또한 뒤로가기 버튼을 통해 상품 목록 페이지로 이동하거나 결제하기 버튼을 통해 결제 모듈로 이동할 수 있습니다.

### 주요 기능
- 장바구니 상품 목록 조회
- 상품 가격 및 수량 기반 총 금액 계산
- 배송비 정책 적용 (10만원 미만 3,000원 / 10만원 이상 무료)
- 뒤로가기 버튼을 통한 상품 목록 페이지 이동
- 결제하기 버튼을 통한 결제 모듈 연동

## 설치 및 실행 방법

프로젝트를 로컬 환경에서 실행하기 위한 방법입니다.

1. 저장소 클론

```

git clone [https://github.com/example/cart-project.git](https://github.com/example/cart-project.git)

```

2. 프로젝트 폴더 이동

```

cd cart-project

```

3. 패키지 설치

```

npm install

```

4. 개발 서버 실행

```

npm start

```

기본 실행 주소  
http://localhost:3000

## 컴포넌트 구조

장바구니 페이지는 다음과 같은 컴포넌트 구조로 구성되어 있습니다.

```

CartPage
├── CartItemList
│     └── CartItem
├── PriceSummary
├── BackButton
└── CheckoutButton

```

### 주요 컴포넌트 설명

**CartPage**
- 장바구니 페이지의 전체 컨테이너
- 장바구니 데이터 관리 및 상태 관리

**CartItemList**
- 장바구니에 담긴 상품 목록을 출력

**CartItem**
- 개별 상품 정보 표시
- 상품 가격 및 수량 표시

**PriceSummary**
- 총 상품 금액 계산
- 배송비 계산
- 최종 결제 금액 표시

**BackButton**
- 클릭 시 메인 상품 목록 페이지로 이동

**CheckoutButton**
- 클릭 시 결제 모듈로 이동

## 테스트 방법

테스트를 실행하려면 다음 명령어를 사용합니다.

```

npm test

```

### 주요 테스트 항목

- 상품 가격 × 수량 계산이 정상적으로 이루어지는지 확인
- 총 금액이 100,000원 미만일 경우 배송비 3,000원이 추가되는지 확인
- 총 금액이 100,000원 이상일 경우 배송비가 무료로 적용되는지 확인
- 뒤로가기 버튼 클릭 시 상품 목록 페이지로 이동하는지 확인
- 결제하기 버튼 클릭 시 결제 모듈로 이동하는지 확인

---

## 유의사항 및 알려진 이슈

- 현재 결제 모듈은 실제 결제 시스템과 연동되지 않은 테스트용 모듈입니다.
- 브라우저 새로고침 시 장바구니 데이터가 초기화될 수 있습니다.
- 일부 브라우저 환경에서 스타일 차이가 발생할 수 있습니다.

장바구니 페이지

구민지

## 📝 고객 요구사항 정리

1. 장바구니에 담긴 상품의 금액을 정확하게 계산하여 사용자에게 보여주어야 한다.
2. 총 상품 금액이 100,000원 미만일 경우 배송비 3,000원을 추가해야 한다.
3. 총 상품 금액이 100,000원 이상일 경우 배송비는 무료로 처리해야 한다.
4. 뒤로가기 버튼을 누르면 메인 상품 목록 페이지로 이동해야 한다.
5. 결제하기 버튼을 누르면 결제 모듈과 연동되어 결제 화면으로 이동해야 한다.

---

## 기능 목록

### 1️⃣ 금액 계산 기능

#### 1.1 개별 상품 금액 계산

* 각 상품의 가격 × 수량을 계산한다.
* 계산 결과는 화면에 즉시 반영된다.
* 수량 변경 시 실시간으로 재계산된다.

#### 1.2 총 상품 금액 계산

* 모든 상품의 개별 금액을 합산하여 총 상품 금액을 계산한다.
* 소수점 없이 원 단위로 표시한다.
* 숫자에 천 단위 구분 쉼표를 적용한다.
  예: 125000 → 125,000원

---

### 2️⃣ 배송비 계산 기능

#### 2.1 배송비 조건 처리

* 총 상품 금액이 100,000원 미만일 경우:

  * 배송비 3,000원을 추가한다.
* 총 상품 금액이 100,000원 이상일 경우:

  * 배송비는 0원으로 처리한다.

#### 2.2 최종 결제 금액 계산

* 최종 금액 = 총 상품 금액 + 배송비
* 배송비 포함 금액을 별도로 표시한다.

예시:

| 총 상품 금액  | 배송비    | 최종 결제 금액 |
| -------- | ------ | -------- |
| 85,000원  | 3,000원 | 88,000원  |
| 120,000원 | 0원     | 120,000원 |

---

### 3️⃣ 뒤로가기 버튼 기능

* 사용자가 뒤로가기 버튼을 클릭하면
  → 메인 상품 목록 페이지로 이동한다.
* React Router를 사용하여 경로 이동 처리한다.
* 이동 시 장바구니 데이터는 유지된다. (상태 관리 필요)

---

### 4️⃣ 결제하기 버튼 기능

#### 4.1 버튼 활성화 조건

* 장바구니에 최소 1개 이상의 상품이 있어야 한다.
* 조건 미충족 시 버튼은 비활성화 처리한다.

#### 4.2 결제 모듈 연동

* 결제하기 버튼 클릭 시:

  * 장바구니 상품 정보
  * 총 결제 금액
  * 배송비 정보
    를 결제 모듈로 전달한다.
* 결제 모듈 페이지로 이동한다.

#### 4.3 예외 처리

* 금액 계산 오류 발생 시 결제 진행 불가
* 장바구니가 비어있을 경우 안내 메시지 출력

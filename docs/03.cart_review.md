# 장바구니 페이지 리뷰

## 고객사 요구사항

본 장바구니 페이지는 고객사에서 전달해주신 이메일 요구사항과 피그마 디자인 시안을 기준으로 개발되었습니다.

### 이메일 기반 요구사항
- 장바구니에 담긴 상품의 금액을 정확하게 계산하여 보여주기
- 총 상품 금액에 따라 배송비 정책 적용
- 뒤로가기 버튼을 통해 상품 목록 페이지로 이동
- 결제하기 버튼을 통해 결제 모듈로 이동

### 피그마 시안 기반 추가 요구사항
- 장바구니에 담긴 상품 목록을 한눈에 확인할 수 있도록 표시
- 총 상품 금액, 배송비, 최종 결제 금액을 구분하여 표시
- 결제하기 버튼을 장바구니 하단에 배치
- 금액 정보는 사용자가 보기 쉽게 정렬하여 표시

---

## 요구사항에 따른 기능 동작 확인

아래는 각 요구사항에 따라 실제 화면에서 어떻게 동작하는지에 대한 설명입니다.

### 1. 장바구니 상품 금액 표시

장바구니에 담긴 상품은 다음과 같은 정보와 함께 표시됩니다.

- 상품 이름
- 상품 가격
- 수량
- 해당 상품의 총 금액

각 상품의 금액은 **상품 가격 × 수량** 기준으로 자동 계산됩니다.  
수량이 변경될 경우 금액도 함께 다시 계산되어 화면에 반영됩니다.

---

### 2. 총 상품 금액 계산

장바구니에 담긴 모든 상품의 금액을 합산하여 **총 상품 금액**을 표시합니다.

예시

| 상품 | 가격 | 수량 | 금액 |
|-----|-----|-----|-----|
| 티셔츠 | 30,000원 | 2개 | 60,000원 |
| 바지 | 40,000원 | 1개 | 40,000원 |

총 상품 금액: **100,000원**

---

### 3. 배송비 정책 적용

배송비는 총 상품 금액에 따라 자동으로 계산됩니다.

- 총 상품 금액이 **100,000원 미만일 경우**
  - 배송비 **3,000원**이 추가됩니다.

- 총 상품 금액이 **100,000원 이상일 경우**
  - 배송비는 **무료**로 적용됩니다.

예시

| 총 상품 금액 | 배송비 | 최종 결제 금액 |
|--------------|--------|----------------|
| 80,000원 | 3,000원 | 83,000원 |
| 120,000원 | 0원 | 120,000원 |

---

### 4. 뒤로가기 버튼 기능

장바구니 페이지 상단에는 **뒤로가기 버튼**이 있습니다.

해당 버튼을 누르면 사용자는  
→ **메인 상품 목록 페이지로 이동**할 수 있습니다.

이를 통해 사용자는 추가 상품을 다시 확인하거나 쇼핑을 계속 진행할 수 있습니다.

---

### 5. 결제하기 버튼 기능

장바구니 하단에는 **결제하기 버튼**이 제공됩니다.

사용자가 이 버튼을 누르면

1. 장바구니에 담긴 상품 정보
2. 총 상품 금액
3. 배송비
4. 최종 결제 금액

이 정보를 기반으로 **결제 모듈 화면으로 이동**하게 됩니다.

---

## 현재 확인된 제한 사항

현재 장바구니 기능은 정상적으로 동작하지만, 다음과 같은 부분은 향후 개선이 필요합니다.

### 결제 모듈 연동

현재 결제하기 버튼은 **결제 모듈 화면으로 이동하는 기능까지 구현**되어 있으며,  
실제 카드 결제나 결제 승인 과정은 테스트 환경 기준으로 동작합니다.

실제 서비스 적용 시에는 결제 시스템과의 추가 연동이 필요합니다.

---

## 종합 의견

현재 장바구니 페이지는 고객사에서 요청한 주요 기능을 기준으로 구현되었으며,

- 상품 금액 계산
- 배송비 정책 적용
- 상품 목록 페이지 이동
- 결제 모듈 연결

과 같은 핵심 기능이 정상적으로 동작하는 것을 확인했습니다.

# 쇼핑몰 연동 프로젝트

## 프로젝트 개요

본 프로젝트는 상품 조회, 장바구니, 결제 기능을 포함한 쇼핑몰 서비스와 결제 모듈을 연동하는 것을 목표로 합니다.  
사용자는 상품을 조회하고 장바구니에 담은 뒤, 결제 과정을 통해 구매를 완료할 수 있습니다.

### 주요 기능
- 상품 목록 조회 및 상세 페이지 이동
- 장바구니 담기 및 수량 관리
- 장바구니 수량 헤더 반영
- 결제하기 버튼을 통한 결제 페이지 이동
- 결제 완료 페이지 표시

### 서비스 URL
https://shopping.vercel.app

### 참여 팀원
- 구민지

## 설치 및 실행 방법

### 1. 저장소 클론
```

git clone [https://github.com/example/shopping-project.git](https://github.com/example/shopping-project.git)

```

cd shopping-project

```

### 3. 패키지 설치
```

npm install

```

### 4. 프로젝트 실행
```

npm start

```

## 프로젝트 구조

```

src
├── pages

│    ├── CartPage

### 주요 구조 설명

- MainPage: 상품 목록 화면
- ProductDetailPage: 상품 상세 정보 표시
- CartPage: 장바구니 목록 및 금액 확인
- PaymentPage: 결제 정보 확인
- PaymentCompletePage: 결제 완료 화면

---

## 주요 함수와 기능

### 1. 상품 상세 페이지 이동
- 상품 클릭 시 상세 페이지로 이동
- 상품 정보 전달 및 표시

### 2. 장바구니 담기 기능
- 상품 추가 시 장바구니에 저장
- 헤더의 장바구니 아이콘 수량 증가

### 3. 수량 변경 기능
- 장바구니 및 상세 페이지에서 수량 조절 가능
- 변경된 수량이 페이지 이동 후에도 유지됨

### 4. 금액 계산 기능
- 상품 가격 × 수량 계산
- 총 금액 자동 업데이트

### 5. 결제 기능
- 결제하기 버튼 클릭 시 결제 페이지 이동
- 결제 완료 시 완료 페이지 표시

## 테스트 방법

### 실행 방법
```

npm test

```

### 기능 테스트 체크리스트

1. 상품 클릭 시 상세 페이지로 이동하는지 확인
2. 상품을 장바구니에 담으면 헤더 수량이 증가하는지 확인
3. 결제하기 버튼 클릭 시 결제 완료 페이지가 정상 표시되는지 확인
4. 수량 변경 후 페이지 이동 시 변경 값이 유지되는지 확인

## 유의사항 및 알려진 이슈

- 현재 결제 기능은 실제 결제 시스템과 연동되지 않은 테스트용 기능입니다.
- 브라우저 새로고침 시 일부 데이터가 초기화될 수 있습니다.
- 일부 브라우저에서 UI 스타일 차이가 발생할 수 있습니다.

## 📝 고객 요구사항 정리

1. 사용자가 장바구니에서 선택한 상품 정보를 결제 모듈로 전달할 수 있어야 한다.
2. 장바구니에서 계산된 최종 결제 금액(상품 금액 + 배송비)이 결제 화면에 정확하게 반영되어야 한다.
3. 결제하기 버튼 클릭 시 결제 모듈 페이지로 이동해야 한다.
4. 결제 모듈에서는 전달받은 상품 정보와 금액을 사용자에게 확인할 수 있도록 보여줘야 한다.
5. 결제 완료 후 쇼핑몰 페이지로 다시 돌아올 수 있어야 한다.
6. 결제 과정 중 오류가 발생할 경우 사용자에게 안내 메시지를 제공해야 한다.

## 📋 기능 목록

---

### 1️⃣ 장바구니 → 결제 모듈 데이터 전달 기능

#### 1.1 전달 데이터 구성

* 상품 목록 (상품명, 가격, 수량)
* 총 상품 금액
* 배송비
* 최종 결제 금액

#### 1.2 데이터 전달 방식

* 결제하기 버튼 클릭 시 결제 모듈로 데이터 전달
* 페이지 이동 시 데이터 함께 전달 (예: 상태값 또는 URL 기반)

---

### 2️⃣ 결제 페이지 정보 표시 기능

* 전달받은 상품 목록을 화면에 표시
* 각 상품의 가격 및 수량 표시
* 총 상품 금액 표시
* 배송비 표시
* 최종 결제 금액 표시

👉 장바구니와 동일한 금액이 표시되어야 함

---

### 3️⃣ 결제하기 버튼 연동 기능

#### 3.1 버튼 동작

* 장바구니에서 결제하기 버튼 클릭 시:
  → 결제 모듈 페이지로 이동

#### 3.2 예외 처리

* 장바구니가 비어 있을 경우 이동 불가
* 금액 정보가 없을 경우 경고 메시지 출력

---

### 4️⃣ 결제 완료 처리 기능

* 결제 완료 시:

  * 성공 메시지 표시
  * 쇼핑몰 메인 또는 주문 완료 페이지로 이동

---

### 5️⃣ 결제 실패 및 오류 처리 기능

* 결제 실패 시:

  * 오류 메시지 표시
  * 다시 시도할 수 있도록 안내

* 네트워크 오류 또는 처리 실패 시:

  * 사용자에게 상황 안내 메시지 제공

---

### 6️⃣ 데이터 일관성 유지 기능

* 장바구니와 결제 페이지 간 금액 차이가 없어야 한다.
* 데이터 전달 과정에서 값이 변경되지 않도록 유지해야 한다.

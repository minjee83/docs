# 쇼핑몰 연동 리뷰

## 고객사 요구사항

본 프로젝트는 고객사에서 전달해주신 이메일 요구사항과 피그마 시안을 기준으로 구현되었습니다.

### 이메일 기반 요구사항
- 상품을 클릭하면 상세 페이지로 이동할 수 있어야 한다.
- 상품을 장바구니에 담을 수 있어야 한다.
- 장바구니에 담긴 상품 수가 화면 상단에 표시되어야 한다.
- 결제하기 버튼을 통해 결제 화면으로 이동할 수 있어야 한다.
- 결제 완료 후 결과 화면을 확인할 수 있어야 한다.

### 피그마 시안 기반 추가 요구사항
- 상품 목록과 상세 페이지가 자연스럽게 연결되어야 한다.
- 장바구니 수량은 사용자에게 직관적으로 보이도록 표시되어야 한다.
- 결제 버튼은 사용자가 쉽게 찾을 수 있는 위치에 배치되어야 한다.
- 수량 변경 시 금액이 즉시 반영되어야 한다.

---

## 요구사항에 따른 기능 동작 확인

아래는 실제 화면에서 각 기능이 어떻게 동작하는지에 대한 설명입니다.

---

### 1. 상품 상세 페이지 이동

- 메인 화면에서 상품을 클릭하면  
  → 해당 상품의 상세 페이지로 이동합니다.
- 상세 페이지에서는 상품 정보와 가격을 확인할 수 있습니다.

동작 상태: 정상 동작

---

### 2. 장바구니 담기 기능

- 상품 목록 또는 상세 페이지에서 “장바구니 담기” 버튼을 누르면  
  → 해당 상품이 장바구니에 추가됩니다.
- 상품이 추가되면 화면 상단의 장바구니 아이콘 숫자가 증가합니다.

동작 상태: 정상 동작

---

### 3. 장바구니 수량 표시

- 장바구니에 담긴 상품 개수가  
  → 상단 아이콘에 숫자로 표시됩니다.
- 여러 상품을 추가하면 숫자가 누적되어 반영됩니다.

동작 상태: 정상 동작

---

### 4. 상품 수량 변경 기능

- 장바구니 또는 상세 페이지에서 상품 수량을 변경할 수 있습니다.
- 수량을 변경하면  
  → 상품 금액과 총 금액이 즉시 다시 계산됩니다.
- 페이지를 이동한 후에도 변경된 수량이 유지됩니다.

동작 상태: 정상 동작

---

### 5. 결제하기 버튼 기능

- 장바구니 페이지에서 “결제하기” 버튼을 누르면  
  → 결제 화면으로 이동합니다.
- 결제 화면에서는 주문 정보와 금액을 확인할 수 있습니다.

동작 상태: 정상 동작

---

### 6. 결제 완료 화면

- 결제를 진행하면  
  → 결제 완료 페이지가 표시됩니다.
- 사용자는 결제 결과를 확인할 수 있습니다.

동작 상태: 정상 동작 (테스트 환경 기준)

---

## 현재 확인된 제한 사항

### 1. 실제 결제 시스템 미연동

현재 결제 기능은 테스트용으로 구현되어 있으며,  
실제 카드 결제나 결제 승인 과정은 포함되어 있지 않습니다.

---

### 2. 데이터 저장 방식

- 브라우저를 새로고침할 경우 일부 장바구니 데이터가 초기화될 수 있습니다.

---

## 종합 의견

현재 쇼핑몰 연동 기능은 고객사에서 요청한 주요 기능을 기준으로 정상 동작하고 있습니다.

- 상품 조회 → 장바구니 → 결제 → 완료  
의 전체 흐름이 자연스럽게 연결되어 있으며,  

기본적인 쇼핑 기능은 문제없이 사용할 수 있는 상태입니다.

향후 실제 결제 시스템과 데이터 저장 기능이 추가되면  
상용 서비스로 확장 가능한 구조입니다.

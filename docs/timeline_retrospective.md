- 2월 21일: 고객 요구사항 분석  
  - 영향: 기능 우선순위가 정리되며 불필요한 개발을 줄일 수 있었음

- 2월 24일: 장바구니 기능 구현  
  - 영향: 쇼핑몰 핵심 기능이 구현되면서 서비스 흐름이 구체화됨

- 2월 28일: 통합 테스트

## 3단계: 개인적 인사이트 도출

- 2월 21일: 고객 요구사항 분석  
  - 영향: 기능 우선순위가 정리되며 불필요한 개발을 줄일 수 있었음  
  - 통찰: 요구사항을 명확히 정의하는 것이 개발 속도보다 더 중요하다는 것을 느낌

- 2월 24일: 장바구니 기능 구현  
  - 영향: 핵심 기능 구현으로 서비스 흐름이 구체화됨  
  - 통찰: 단순 기능 구현보다 상태 관리가 더 중요하다는 것을 체감

- 2월 26일: 금액 계산 로직 구현  
  - 영향: 결제 금액이 자동 계산되며 사용자 경험 개선  
  - 통찰: 작은 계산 로직도 정확성과 예외 처리가 중요함을 인식

- 2월 27일: 결제 모듈 연동  
  - 영향: 전체 서비스 흐름 완성  
  - 통찰: 페이지 간 데이터 전달 구조 설계가 핵심이라는 것을 이해

- 2월 28일: 통합 테스트  
  - 영향: 오류 사전 발견 및 수정  
  - 통찰: 기능 단위 개발보다 통합 테스트가 더 많은 문제를 드러낸다는 것을 경험

  - 액션 플랜: 기능 개발과 동시에 테스트 케이스 작성
